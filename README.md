# Data Visualisation

Python notebooks that practise data visualisation with Matplotlib and Seaborn.

## Branches

- `matplotlib`: the Matplotlib notebook
- `seaborn`: the Seaborn notebook

Use the branch dropdown at the top left of the repo page to switch between them.

## Requirements

- Python 3
- Jupyter Notebook or VS Code with the Jupyter extension
- Install the libraries with: pip install matplotlib seaborn pandas

## How to run

1. Open the branch you want.
2. Open the notebook.
3. Click Run All.
